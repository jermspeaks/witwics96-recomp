# Where in the World Is Carmen Sandiego? — macOS Port

A project to make the 1990s Windows game identified by the project owner playable on a modern Mac.

## Bring your own game copy

This repository does not include the original game or proprietary game files. You must provide your own legally obtained copy. The local `input/` directory is intentionally excluded from Git; do not commit the game, extracted proprietary assets, or other copyrighted payloads. See [AGENTS.md](AGENTS.md) for project handling rules.

## Project tracking

- [Findings ledger](docs/findings.md) — current observations, evidence limits, and open questions.
- [Plan and handoff](docs/plan.md) — phases, status, and next actions.
- [Gameplay spec (draft)](docs/gameplay-spec.md) — clean-room loop, data model, and minimum-playable milestone.

The initial inventory is metadata-only. The exact game release, formats, dependencies, macOS approach, and playable scope remain to be established; see the findings and plan before making assumptions.
